# Security Policy

## Supported versions
This repository is an early-stage static website. Security fixes are applied to the current `main` branch; there are no separately maintained release branches.

## Reporting a vulnerability
Please **do not** publish exploitable security details in a public issue. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if it is enabled for this repository. If it is not enabled, contact the maintainer privately through a contact channel they have explicitly published; do not post sensitive details publicly. Ordinary bugs and feature requests belong in GitHub Issues.

The maintainer will review reports as available. There is no guaranteed response time or security warranty.
