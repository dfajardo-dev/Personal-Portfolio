# Roadmap (draft, October 2026–October 2027)

This roadmap is a plan, not a claim that features already exist.

- **Late 2026:** Replace sample project text with confirmed project links, screenshots, and accurate descriptions.
- **Early 2027:** Improve accessibility and test the site with keyboard navigation and mobile layouts.
- **Mid 2027:** Add project detail pages, if useful, without collecting visitor personal information.
- **Late 2027:** Review maintenance, dependencies, and security documentation; publish a stable site version.

Out of scope: user accounts, payments, and collecting personal information from visitors.
